One haiku about debugging, in the 5-7-5 syllable shape:

> Stack trace at dawn breaks
> a null hides where I looked twice
> I wrote it myself

Seventeen syllables, three lines, 78 characters. The picture is concrete — a
stack trace at dawn, a null hiding where I already looked twice — and the last
line turns it: the bug I chased all night was mine all along.
